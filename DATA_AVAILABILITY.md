# Data availability

The paper uses 17,812 training queries over 8,796 trajectories and an active
evaluation suite containing 36,726 queries. The public dataset repository is
metadata-only while source-specific redistribution review remains incomplete.

It contains summaries, effective configurations, source/revision metadata,
expected file sizes, and SHA-256 hashes. It intentionally excludes raw JSONL
rows. Sources with gated or unclear redistribution terms must be obtained from
their original providers and reconstructed locally.

Explicitly recorded reusable sources include IFBench (ODC-BY-1.0), SRA-Bench
(Apache-2.0), SycoBench-600 (CC-BY-4.0), and Terminal Wrench (Apache-2.0).
Other sources remain subject to the detailed audit in the metadata repository.
